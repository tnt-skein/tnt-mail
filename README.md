# tnt-mail

Почта для Tarantool: письмо уходит по SMTP, а забирается по POP3 или
IMAP. Письмо собирается и разбирается целиком — с темой по RFC 2047,
разметкой, вложениями и чужими кодировками, — шифрование поднимается
с первого байта или командой STARTTLS, а отказ — пара, а не исключение.

```lua
local mail = require('tnt.mail')

mail.configure({ from = 'tarantool@example.org', smtp = { host = '127.0.0.1', port = 1025 } })
local ok, err = mail.send({ to = 'duty@example.org', subject = 'Реплика отстала', text = 'Подробности' })
```

Письма приложения объявляются один раз — тема, получатели, вид
на `tnt-template` и данные: обе части письма собираются из одного вида,
уходит оно очередью с повторами, а посмотреть его можно в браузере,
ничего не отправляя. Каждая отправка видна рядами метрик: `mail_sent_total`
по итогу — `sent` либо род отказа — и длительность разговора с сервером.

Зависимости: `tnt-tls` (шифрование поверх сокета), `tnt-str` (перевод
чужих кодировок в UTF-8), `tnt-id` (ULID для `Message-ID`), `tnt-log`
(запись о неотправленном письме), `tnt-must` (отказ настройки и проверки
аргументов), `tnt-fs` (файлы предпросмотра), `tnt-metrics` (ряды отправок),
`tnt-clock` (длительность разговора с сервером) и `tnt-external` (подмена
сети, шифрования, часов и вывода в проверках). Шаблоны и очередь писем
приходят аргументами.

## Зачем

Узлу нужна почта по двум поводам: сказать человеку, что случилось,
и прочитать ответ. SMTP отправляет, POP3 забирает письма насовсем, IMAP
смотрит их, не отнимая у человека, который читает тот же ящик. Пакет
делает шесть вещей:

- **Не отдаёт пароль молча.** Вход с паролем без шифрования запрещён,
  пока его не признали настройкой `allow_plaintext_auth`; способ входа
  в SMTP выбирается из объявленных сервером — CRAM-MD5, PLAIN, LOGIN,
  а XOAUTH2 входит по токену OAuth 2.0 по всем трём протоколам, и пароль
  тогда — функция-поставщик, которая отдаёт живой токен перед каждым
  входом.
- **Собирает письмо целиком.** Тема с кириллицей, base64 строками
  по 76 знаков, текст с разметкой, вложения с именем по RFC 2231, дата
  по-английски при любой локали, `Message-ID` всегда, точка в начале
  строки удвоена.
- **Читает чужие письма терпеливо.** Перенесённые заголовки, base64
  и quoted-printable, вложенные части; тема, текст и имя вложения
  переводятся в UTF-8 по объявленной кодировке, содержимое вложения
  остаётся байтами.
- **Не роняет узел.** Отказ возвращается причиной, у каждой операции
  свой срок, соединение закрывается в любом исходе — и после STARTTLS
  закрывается защищённое.
- **Не пускает перевод строки в команды.** Управляющий знак в адресе,
  своём заголовке, дате или идентификаторе — отказ до сборки.
- **Держит письма приложения объявлениями.** Простой текст выводится
  из той же разметки, ссылка в нём — с адресом; письмо уходит очередью
  с тем же `Message-ID` при каждом повторе, отказ 4xx повторяется,
  5xx зарывается сразу; `make mail-preview` кладёт письма в файлы
  для браузера.

## Установка

```sh
tt rocks install tnt-mail --server=https://tnt-skein.github.io/rocks
```

Или из исходников:

```sh
git clone https://github.com/tnt-skein/tnt-mail.git
cd tnt-mail && tt rocks make
```

## Как пользоваться

| Вызов | Что делает |
|---|---|
| `mail.configure(opts)` | задаёт настройки; негодная — исключение сразу |
| `mail.send(letter)` | отправляет письмо; `true` либо `false, err` |
| `mail.render(letter)` | собирает письмо, не отправляя; текст либо `nil, err` |
| `mail.fetch(opts)` | забирает письма, свежие первыми; список либо `nil, err` |
| `mail.folders()` | папки ящика по IMAP |
| `mail.status()` | что настроено, без паролей |
| `mail.parse.of(raw)` | разбирает письмо из строки |
| `mail.letters(opts)` | письма объявлениями: `declare`, `send`, `queue`, `handler`, `preview` |
| `mail.refusal.of(err)` | разбирает отказ отправки: род, повтор, код, получатель |
| `mail.text.of(html)` | простой текст из разметки |

```lua
mail.configure({
    from = { name = 'Узел storage-001-a', address = 'tarantool@example.org' },
    host = 'mail.example.org',
    tls = 'starttls',
    username = 'node',
    password = secret,
})

mail.send({
    to = { { name = 'Дежурный', address = 'duty@example.org' } },
    subject = 'Отчёт за сутки',
    text = 'Отчёт во вложении',
    attachments = { { name = 'report.csv', type = 'text/csv', content = csv } },
})

for _, letter in ipairs(mail.fetch({ via = 'imap', unseen = true, limit = 5 }) or {}) do
    print(letter.subject, letter.from, letter.text)
end

local queue = require('tnt.queue')
local template = require('tnt.template')

local letters = mail.letters({
    views = template.new({ path = 'resources/views' }),
    queue = queue.declare('mail', { ttr = 60 }),
})

letters:declare('confirm', {
    subject = 'Подтвердите почту',
    to = function(data)
        return data.email
    end,
    view = 'mail.confirm',
})

letters:queue('confirm', { email = 'maria@example.org', link = link })
queue.declare('mail', { ttr = 60 }):consume(letters:handler())
```

Общие настройки годятся всем трём протоколам, свои (`smtp`, `pop3`,
`imap`) их перекрывают. Порт по умолчанию следует способу шифрования:
`none` — 25, 110, 143; `starttls` — 587, 110, 143; `direct` — 465, 995,
993. Сертификат проверяется по корням системы, свои называют `ca_file`
или `ca_path`.

## Проверки

```sh
make deps          # luatest, luacheck, luacov с cluacov и зависимости пакета в .rocks
make check         # форматирование, линт, проверки, покрытие с порогом 100 %
make mutants-all   # мутационное тестирование утилитой tnt-mutants из PATH, порог 100 % убитых
make mail-up       # Mailpit, GreenMail и smtp4dev в докере для живых проверок; make mail-down — погасить
```

Покрытие строк — 100 %, убитых мутантов — 100 % (427 проверок, 14 из
них живые, 1418 мутантов в тринадцати модулях). Протоколы проверяются
разговором с двойником сервера, а живая проверка ходит на Mailpit,
GreenMail и smtp4dev; без них она пропускается. Письма приложения
проверяются на настоящих шаблонах, с настоящей очередью `tnt-queue`
на временном узле и живой отправкой очередью на Mailpit.
